# NEJE Studio

NEJE 블루투스 레이저 각인기(Master 2 / 2S 시리즈)용 비공식 안드로이드 앱입니다.
제조사 앱의 BLE 프로토콜을 분석해 새로 만들었습니다.

## 주요 기능

- **이미지 불러오기**: 갤러리 앱 / 파일 / 사진 선택기, 자르기, 90° 회전, 크기 조절
- **텍스트 입력**: 여러 줄, 글자 크기(mm), 글꼴, 굵게 (한글 지원)
- **변환 방식**: 흑백 / 디더링 / 테두리만 (선 두께 조절)
- **작업 구역**: 가로·세로(mm)와 영점 위치(좌상·우상·좌하·우하) 설정
- **캔버스 편집**: 이미지와 텍스트를 여러 개 배치, 드래그로 이동, 핀치로 크기 조절, mm 단위 직접 입력
- **화면 확대·축소**: 핀치 또는 +/−/맞춤 버튼
- **영점 맞추기**: 개체 하나, 또는 전체를 영점 모서리에 정렬
- **위치 확인**: 약한 레이저로 각인 영역 테두리 표시 (화면에도 테두리와 위치 표시)
- **헤드 이동 (테스트용)**: X/Y 이동, 영점 복귀, 화면에 헤드 위치와 영점에서의 이동량 표시
- **모터 방향 반전**: X축 / Y축 (앱에서 좌표·이미지를 뒤집어 보정)
- **프리셋**: 각인 시간·레이저 파워 저장
- 진행률, 배터리·레이저 온도 표시, 기울기 경보 해제

## 빌드

필요: JDK 17, Android SDK (platform 35, build-tools 35)

```bat
build.bat          :: 디버그 APK 빌드
build.bat test     :: 단위 테스트 후 빌드
build.bat clean    :: 정리 후 빌드
```

결과물: `NejeStudio-<버전>-debug.apk`

## 구조

```
docs/PROTOCOL.md         BLE 프로토콜 정리
NejeStudio/              안드로이드 앱 (Kotlin + Jetpack Compose)
  app/src/main/java/com/nejestudio/
    ble/                 프로토콜, BLE 연결
    imaging/             흑백 변환, 디더링, 테두리 추출, 텍스트 렌더링
    model/               데이터 모델, 좌표 변환
    data/                설정·프리셋 저장
    ui/                  화면
build.bat                빌드 스크립트
```
